# 🚪 BOYNEXTDOOR 스케줄 & 출퇴근 관리 시스템 (Attendance System)

파이썬으로 제작한 **보넥도(BOYNEXTDOOR) 멤버 및 소속 스태프 크루**들의 출퇴근과 스케줄을 관리하는 CLI(Command Line Interface) 기반 프로그램입니다. 

## ✨ 주요 기능 (Features)

* **보안 출퇴근 등록**: 멤버별/크루별 고유 비밀번호를 통한 출근 및 퇴근 인증 시스템
* **스마트 정원 관리**: 
  * 멤버: 1인 정원 시스템 (`1/1`)
  * 스태프 크루: 팀 단위 다수 인원 관리 (최대 12명 정원, `n/12`)
* **개인 맞춤형 스케줄 연동**: 출근 등록 완료 시, 해당 인원의 당일 상세 스케줄 확인 여부 프롬프트 제공
* **실시간 대시보드**: 프로그램 실행 시 현재 시간 기준의 전체 인원 출결 상태를 한눈에 파악 가능
* **대화형 인터페이스(Interactive CLI)**: 무한 루프를 통해 프로그램 종료 전까지 지속적인 출퇴근 및 현황 확인 가능

## 🛠 사용 기술 (Tech Stack)

* **Language**: Python 3.x
* **Libraries**: `datetime` (내장 라이브러리)

## 🚀 실행 방법 (How to Run)

1. 저장소를 클론(Clone)하거나 다운로드합니다.
> git clone [레포지토리 주소]

2. 파이썬 환경에서 스크립트를 실행합니다.
> python [파일명].py

3. 터미널의 안내에 따라 '예/아니요', '출근/퇴근', '이름', '비밀번호'를 입력하며 시스템을 사용합니다.

## ✍️ 개발 노트 (Developer's Note)

* 딕셔너리(`dict`) 구조를 활용하여 인원별 비밀번호와 스케줄 데이터를 효율적으로 바인딩했습니다.
* 리스트 언패킹(`curr, total = ...`) 문법을 적용하여 코드의 가독성을 높였습니다.
* 사용자 입력 시 발생할 수 있는 공백 오류를 방지하기 위해 `.strip()` 메서드를 활용한 방어 코드를 구축했습니다.
